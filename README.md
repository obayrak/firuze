# Firuze

A nuclear-reaction workbench in a single HTML file: optical model, coupled channels, transfer, capture, R-matrix, Exfor import and fitting, reaction rates, compound nucleus (Hauser–Feshbach) and an illustrated "How Firuze works" tab, with a built-in theory section.

- **Open it:** `index.html` (desktop) or `mobile.html` (phone layout). No installation; it runs in the browser. MathJax and Plotly are loaded from cdnjs, so an internet connection is needed.
- **Online:** with GitHub Pages enabled (Settings → Pages → Deploy from branch → `main`, `/ (root)`), the app is served at `https://<user>.github.io/<repo>/`.
